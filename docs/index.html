Apple Calendar

  1. Open Calendar.
  2. Choose File → New Calendar Subscription.
  3. Paste the URL above and choose Subscribe.

Calendar clients choose their own subscription refresh cadence; this is not an instant notification service.

Data is generated from codex-reset.com’s public feed and links each event to its original public X post. This independent project is not affiliated with or endorsed by OpenAI, ChatGPT, Codex, or X, and does not guarantee eligibility or timing.
